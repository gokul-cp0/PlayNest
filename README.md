# PlayNest - [Live Demo 👆](https://gokul-cp0.github.io/PlayNest/)

**PlayNest** is a game purchasing website template designed using **HTML and CSS**. This project was built during my HTML/CSS training to showcase my ability to create structured layouts, visually engaging designs, and user-focused interfaces.

This project helped me to:
- Understand page layout principles
- Practice CSS styling and positioning
- Learn how to create visually engaging components using only HTML & CSS
